# MugenCC0UsefulLibs

Reusable libraries and tooling for M.U.G.E.N-compatible projects, released under CC0 where the repository owner holds the relevant rights.

## Libraries

- [`sff_fixed89`](sff_fixed89/) — C89 SFF v1/v2 parser and sprite decoder; fixed-capacity, no heap, caller-owned buffers, PCX/PNG support.

Each library carries its own documentation, license-scope notice, tests, and build instructions. Third-party formats, trademarks, characters, artwork, and corpus files remain the property of their owners.
